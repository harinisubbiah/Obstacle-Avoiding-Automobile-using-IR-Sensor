# Obstacle-Avoiding-Automobile-using-IR-Sensor
The primary objective of this project is to design and develop an autonomous robot that intelligently navigates its surroundings using IR sensors, while delivering real-time feedback through a buzzer alert system.

# 🔩 Hardware Components Used
✅ AT89S52 Microcontroller

✅ L293D Motor Driver IC

✅ 3 TSOP18638 IR Sensors

✅2 DC Motors

✅ BC547 NPN Transistor

✅ 1K Resistor

✅ Buzzer

✅ 5V Power Supply

✅ Connecting Wires

✅ Breadboard

# 💻 Software Required
➡️ Keil uVision

# How it Works
• This project features an autonomous robot car built using an 8051 microcontroller and three IR sensors (front, left, right).

• The IR sensors detect nearby surfaces or obstacles. Based on sensor input, the robot navigates by turning or moving forward.

• A buzzer provides real-time alerts at junctions or when all sensors detect obstacles.

# ⚙️ Set up
1.Connect the ciruit as per the given schematic diagram.

2.Create a new project assigning the device as AT89S52.

3.Upload the code into Keil uVision assembly language file and configure the output file to a hexfile.

4.Connect the board to the laptop and upload the code using the ISP Program driver.
